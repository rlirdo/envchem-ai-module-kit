★基礎題（單選／填空）　建議作答 10 分鐘8 題 × 8 分＝64 分

1什麼是 API（Application Programming Interface）？8 分
（A）只能用瀏覽器打開、給人看的網頁（B）程式之間「用網址提出請求、對方回傳資料」的約定介面，程式可以直接讀取（C）一種 Excel 試算表的檔案格式（D）Google Colab 的付費功能
2環境部 API 網址 https://data.moenv.gov.tw/api/v2/aqx_p_488?api_key=…&format=JSON 中，粗體的 aqx_p_488 是什麼？8 分
（A）測站代碼（花蓮站）（B）使用者帳號（C）資料集代碼 DataID（空氣品質監測小時值，歷史）（D）抓取日期
3網址裡的 api_key（API 金鑰）性質最接近下列哪一項？8 分
（A）公開的網站名稱，任何人都可以看（B）測站的地址（C）檔案的副檔名（D）個人的帳號密碼：代表「你」在使用平臺，不可外流
4環境部 API 回傳的 JSON 格式，下列敘述何者正確？8 分
（A）是用「鍵：值」成對排列的文字資料（如 "sitename": "花蓮"），程式容易讀成表格（B）只能用 Excel 打開（C）是一種圖片格式（D）必須先列印出來才能閱讀
5你想畫「花蓮站近一個月 O₃ 的日變化」。該用哪一支資料集？8 分
（A）aqx_p_432：AQI 現況，每小時更新、只有最新一筆（B）兩支都不行，只能人工抄監測網（C）aqx_p_488：空氣品質監測小時值，可回溯歷史逐時資料（D）哪一支都一樣
6關於 API 金鑰的安全，下列哪一個做法正確？8 分
（A）把金鑰直接寫在程式碼第一行，再把筆記本分享給全組（B）把真正的金鑰貼進 Gemini 對話，請它幫我寫程式（C）存在 Colab「密鑰」中，程式用 userdata.get('MOENV_API_KEY') 讀取；截圖前先遮住（D）金鑰只是一串亂碼，截圖不必遮蔽
7好的 Prompt 有 6 個零件：① 任務 ② 資料來源＋樣本 ③ 英文欄位名 ④ 輸出形式 ⑤ 限制與說明 ⑥ 驗證。下列哪一句屬於「⑥ 驗證」？8 分
（A）你是一個 Python 資料科學家（B）請先印出欄位名稱和前 5 筆資料讓我確認，再往下做（C）請在程式碼加上詳細的中文註解（D）把結果整理成 DataFrame 並存成 CSV
8單位與化學意義填空：O₃、NO₂、NOₓ 欄位的單位是 （體積比），PM₂.₅ 的單位是 （質量濃度）；NOₓ ＝ ＋ 。8 分

★★進階題（簡答）　建議作答 10 分鐘3 題 × 12 分＝36 分

9同學寫了這個 Prompt 給 Gemini：「幫我抓花蓮的空氣資料。」結果 AI 寫出的程式抓錯資料集、欄位也不對。請把它改寫成一個好 Prompt（至少包含 6 個零件中的 4 個），並在句尾用括號標出你用了哪些零件。12 分
10小花把金鑰寫在 Colab 程式碼第一行，再把筆記本設成「知道連結的任何人都可以檢視」貼到班級群組。請指出兩個風險，並寫出她應該怎麼做（至少兩個步驟）。12 分
11某天花蓮站 O₃ 讀值 46.7 ppb、PM₂.₅ 讀值 20 μg/m³，同學說「所以 O₃ 比 PM₂.₅ 嚴重」。請說明為什麼這兩個數字不能直接比大小，並說明 AQI 與這些濃度值有什麼不同。12 分
