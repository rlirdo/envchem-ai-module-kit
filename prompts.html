Prompt 指南

好 Prompt 的 6 個零件

Prompt-driven：不用背語法，但要會描述需求、看懂結果、發現錯誤
零件寫什麼範例
① 任務想回答什麼問題（最重要）我想看花蓮站近一個月 PM2.5、O3、NO2 的變化
② 資料來源＋樣子網址或檔案、2–3 筆樣本、測站與時間範圍環境部 API（金鑰用 API_KEY 變數）；貼 2 筆 JSON：{"sitename":"花蓮","pm2.5":"4","o3":"30","publishtime":"2026/10/17 17:00:00"}
③ 欄位（英文名）用資料裡真正的欄位名稱publishtime、sitename、pm2.5、o3、no2（不要寫「監測時間」讓 AI 猜）
④ 輸出形式要表格、圖或檔案整理成 DataFrame、存成 CSV；或畫折線圖
⑤ 限制與說明環境、語言、角色能在 Colab 執行、加中文註解；畫圖時「請處理 Colab 中文字型」；你是 Python 資料科學家
⑥ 驗證請 AI 先讓你檢查先印出欄位名稱和前 5 筆讓我確認，再畫圖；每段程式說明在做什麼
金鑰存在 Colab「密鑰」，用 userdata.get('MOENV_API_KEY') 讀；不要把真的金鑰、同學姓名學號貼給 AI。一次只問一件事：活動一抓資料，活動二再畫圖。每一次修改 Prompt 都記到學習單的「Prompt 紀錄表」。

模組活動一

步驟 4-2｜今天的 Prompt 模板（申請書原版）

第 4 步｜第一次對話：AI 生成程式碼｜看操作手冊
你是一個 Python 資料科學家。我有一個環境部空氣品質開放資料的 API 網址： https://data.moenv.gov.tw/api/v2/aqx_p_432?api_key={API_KEY}&limit=1000&format=JSON （金鑰已經存在變數 API_KEY 裡） 我不會寫程式，請幫我寫出一段可以在 Google Colab 運行的 Python 程式碼，功能是要抓取這個網址的資料，並將裡面的監測時間、PM2.5、O3 欄位整理成一個乾淨的表格（DataFrame）顯示出來。 請在程式碼裡加上詳細的中文註解。

步驟 4-3｜改良版 Prompt：補上任務、資料樣子、驗證

第 4 步｜第一次對話：AI 生成程式碼｜看操作手冊
【① 任務】我想知道花蓮站現在的空氣品質，並和全臺其他測站比較 PM2.5、O3、NO2。 【② 資料來源＋樣子】環境部 API：https://data.moenv.gov.tw/api/v2/aqx_p_432?api_key={API_KEY}&limit=1000&format=JSON（金鑰已用 userdata.get 存在變數 API_KEY）。回傳是 JSON 清單，每筆像這樣： {"sitename":"花蓮","county":"花蓮縣","aqi":"27","pm2.5":"4","o3":"30","no2":"1","publishtime":"2026/10/17 17:00:00", …} 【③ 欄位】sitename、county、publishtime、pm2.5、o3、no2（數值是文字） 【④ 輸出】整理成 DataFrame，數值轉成數字 【⑤ 限制】你是 Python 資料科學家；程式要能在 Google Colab 執行，加上詳細中文註解 【⑥ 驗證】先印出欄位名稱和前 5 筆讓我確認，再印出總共幾個測站

步驟 6-1｜兩段 Prompt：篩出花蓮、抓近一個月歷史

第 6 步｜花蓮資料落地存 CSV｜看操作手冊
【篩花蓮（現況）】 請把上面的 df_now 只留下 sitename 等於「花蓮」的那一列，並顯示 publishtime、aqi、pm2.5、o3、no2、nox、wind_speed 這幾個欄位。 【抓歷史（近一個月）】 請幫我寫 Colab 程式碼，用環境部 API 的 aqx_p_488（空氣品質指標歷史資料），加上參數 filters=sitename,EQ,花蓮 和 sort=datacreationdate desc，limit=1000，把花蓮站的資料抓下來，轉成 DataFrame，並告訴我資料的最早與最晚時間、總共幾筆。

模組活動二

步驟 2-2｜盤點 Prompt：哪些值「不是數字」？

第 2 步｜盤點與清除無效值｜看操作手冊
我的 DataFrame 叫 df，欄位都是文字。 請幫我寫 Python 程式碼，檢查 o3、no2、nox、pm2.5 這幾欄裡，有哪些「不是數字」的值（例如空白、x、-999、ND），各出現幾次。

步驟 2-4｜清洗 Prompt：申請書原版 vs. 改良版

第 2 步｜盤點與清除無效值｜看操作手冊
【申請書原版】 我的環境數據中，有些數值是 -999，這代表無效值。請幫我寫 Python 程式碼，把這些無效值剔除，並計算 PM2.5 和 O3 的平均值、最大值與最小值。 【改良版：寫進你的盤點結果】 我的 DataFrame 叫 df，欄位都是文字。這份花蓮站資料的無效值是空白（讀進來已變成 NaN），aqx_p_13 資料集則用「x」。請把 aqi、so2、co、o3、pm10、pm2.5、no2、nox、no、windspeed、winddirec 轉成數字，無效值一律變成 NaN（不要填 0、不要刪整列），印出每欄清掉幾筆，結果存成新表 clean（不要改動 df），再計算 PM2.5 和 O3 的平均值、最大值與最小值。

步驟 3-2｜結構化 Prompt：時間欄＋小時欄＋存檔

第 3 步｜時間欄位與結構化｜看操作手冊
請把 clean 的 datacreationdate 轉成日期時間格式，新增一欄 hour（0–23 點），依時間排序，再存成 hualien_clean.csv（utf-8-sig）。 【加碼】 請再檢查從最早到最晚應該有幾個小時、實際有幾列，並列出缺少的時間點。

步驟 4-2｜繪圖 Prompt：申請書原版＋改良版

第 4 步｜24 小時折線圖｜看操作手冊
【申請書原版】 請幫我寫 Colab 程式碼，使用 matplotlib 或 seaborn 畫出一張折線圖。X 軸是時間（一天 24 小時），Y 軸同時畫出 PM2.5 與 O3 的濃度變化，並用不同顏色區分。請確保圖表標題與標籤可以顯示中文。 【改良版：補上資料範圍、單位、字型、檔名】 資料用 clean 裡 O3 最高的那一天（24 小時）。請處理 Colab 中文字型（先執行 ma.use_chinese_font()，避免中文變成方塊），化學式寫 O3、PM2.5，不用下標字元。O3 單位是 ppb、PM2.5 是 μg/m³，請把單位寫進圖例；標題寫出測站與日期，存成 fig1_一天24小時.png。畫圖前先印出這一天的 24 筆資料讓我確認，並說明每段程式在做什麼。

步驟 5-1｜散佈圖 Prompt：NOx 與 O3 有關係嗎？

第 5 步｜NOx–O3 散佈圖與相關｜看操作手冊
請用 clean 畫一張散佈圖：X 軸是 NOx（ppb），Y 軸是 O3（ppb），點的顏色代表 hour（0–23 點），加上色條、中文標題，並計算兩者的相關係數 r 顯示在標題上。

步驟 6-1｜優化：30 天平均日變化雙 Y 軸圖

第 6 步｜圖表優化與時空分析｜看操作手冊
請把 clean 依 hour 分組，算出每個小時 O3、NO2 的平均值，畫成雙 Y 軸折線圖（左軸 O3、右軸 NO2），並標出 O3 最高的時間點。 【校正要求】 標題寫「花蓮站近 30 天平均日變化：O3 與 NO2」，兩個 Y 軸都要標單位（ppb），存成 fig3_日變化雙軸.png，最後印出每小時平均值表。

模組活動三

步驟 1-3｜申請書原版 Prompt（先當「對照組」）

第 1 步｜把圖表與數據交給 AI｜看操作手冊
這是我撈取花蓮測站春季的數據圖。我發現每天下午 1 點到 3 點，臭氧（O3）濃度會達到峰值，而氮氧化物（NOx）在早上 8 點最高後開始下降。請從環境化學、大氣光化學反應機制的角度，幫我解釋為什麼會出現這種現象？

第 1 步｜把圖表與數據交給 AI｜看操作手冊
【數據摘要】（貼上 Colab 步驟 1 印出的文字） 這是我撈取花蓮測站的數據摘要（如上）。我發現 O3 在中午 12–14 點達到峰值，而 NO2 在晚上 7–9 點最高。請從環境化學、大氣光化學反應機制的角度，幫我解釋為什麼會出現這種現象？ 請把你的解釋分成「條列的主張」，每一條都寫出相關的化學反應式，並註明你的依據。
